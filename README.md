# Mi primer JavaScript

Este proyecto fue realizado para aprender los fundamentos de JavaScript Vainilla y el uso de Git y GitHub.

## ¿Qué aprendí?

Durante el proyecto aprendí:

- Qué es JavaScript Vainilla.
- Cómo declarar variables con `let` y `const`.
- Los tipos de datos básicos.
- Operadores matemáticos y comparadores.
- Estructuras condicionales.
- Cómo crear y utilizar funciones.
- Qué es el DOM.
- Cómo utilizar `querySelector`.
- Cómo utilizar `addEventListener`.
- Cómo crear una página web interactiva.
- Cómo guardar y subir proyectos utilizando Git y GitHub.

## Proyecto final

El proyecto final es un contador dinámico que permite aumentar y disminuir un número mediante botones.

El contador cambia de color dependiendo de su valor:

- Verde: cuando es mayor que 0.
- Rojo: cuando es menor que 0.
- Oscuro: cuando es igual a 0.
